# PizzaTimeApp

WPF-приложение для управления пиццерией «PizzaTime».

## Назначение

Приложение позволяет:
- Авторизовываться по логину и паролю.
- Разграничивать права доступа по ролям (администратор, менеджер, пользователь).
- Просматривать список заказов.
- Оформлять новые заказы (с выбором клиента, пиццы и способа оплаты).
- Управлять заказами (просмотр, удаление).
- Управлять меню (просмотр, удаление товаров).
- Управлять пользователями (просмотр).

## Технологии

- Язык: C#
- Платформа: WPF (.NET Framework 4.7.2)
- База данных: Microsoft SQL Server
- ORM: Entity Framework 6 (Database First)
- Среда разработки: Microsoft Visual Studio

## Структура проекта

- `Models/` — модель базы данных (EDMX), сущности и контекст.
- `Views/` — страницы приложения (LoginPage, MainPage, OrdersPage и др.).
- `App.xaml` — точка входа приложения.
- `MainWindow.xaml` — главное окно (контейнер для страниц).

## Роли пользователей

- **admin** — полный доступ (управление заказами, меню, пользователями).
- **manager** — управление заказами и меню.
- **user** — просмотр и оформление своих заказов.

## Запуск

1. Открыть решение `PizzaTimeApp.sln` в Visual Studio.
2. Восстановить пакеты NuGet (Entity Framework).
3. Убедиться, что база `PizzaTime` доступна на сервере `DESKTOP-RAJVH1A\SQLEXPRESS`.
4. Нажать F5.
