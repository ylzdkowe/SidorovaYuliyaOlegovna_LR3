# 1. Название проекта и краткое описание (Elevator Pitch)

**PizzaTimeApp**

Учебное приложение для управления пиццерией «PizzaTime», разработанное для автоматизации заказов, учёта меню и клиентов. Позволяет разграничивать права доступа (администратор, менеджер, клиент) и управлять заказами в реальном времени.

# 2. Установка (Installation)

Для запуска приложения необходимо:

- Установить **Microsoft Visual Studio** (с поддержкой .NET Framework 4.7.2).
- Установить **SQL Server** (Express версии достаточно).
- Восстановить базу данных `PizzaTime` на вашем локальном сервере (скрипт создания БД и таблиц находится в папке с проектом).
- Открыть файл решения `PizzaTimeApp.sln` в Visual Studio.

# 3. Использование (Usage)

1. Запустите приложение (F5 в Visual Studio).
2. Введите логин и пароль на странице авторизации.
3. Используйте кнопки главного меню для навигации:
   - **Оформить заказ** — выбор клиента, пиццы и оплаты.
   - **Управление заказами** (доступно админу и менеджеру) — просмотр и удаление.
   - **Управление меню** — просмотр и удаление товаров.
   - **Управление пользователями** (только админ).

**Тестовые данные для входа:**

- **Админ:** логин `admin`, пароль `admin123`
- **Менеджер:** логин `manager`, пароль `manager123`
- **Пользователь:** логин `user`, пароль `user123`

# 4. Структура проекта

- `PizzaTimeApp/Models/` — модель базы данных (EDMX), контекст и классы сущностей.
- `PizzaTimeApp/Views/` — WPF-страницы приложения (авторизация, меню, заказы).
- `PizzaTimeApp/App.xaml` — точка входа и глобальные настройки (текущий пользователь).
- `PizzaTimeApp/MainWindow.xaml` — главное окно (контейнер для страниц).

# 5. Данные (Data)

Приложение использует базу данных **Microsoft SQL Server**.

- **Структура БД:** 8 таблиц (пиццы, категории, клиенты, заказы, позиции заказов, платежи, способы оплаты, курьеры) + добавленная таблица `Users` для авторизации.
- **Строка подключения:** настраивается в файле `App.config` (параметр `PizzaTimeEntities1`).
- **ORM:** Entity Framework 6 (Database First).
